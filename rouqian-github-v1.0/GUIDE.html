把「揉钱」放上 GitHub，
在 Mac 和 iPhone 上使用

无需微信开发者工具、Xcode、终端或编程。你需要一个 GitHub 账号、这份解压后的文件，以及电脑浏览器。

GitHub 存放和发布软件；账单保存在你的设备。Mac 与 iPhone 不会自动同步。不要把个人账本备份上传到 GitHub。

1．下载、解压，找到正确文件层级

  1. 下载对话中的 rouqian-github-v1.0.zip。
  2. Mac 双击 ZIP 解压。在解压目录里找到 index.html；它旁边应有 app.js、style.css、sw.js、manifest.webmanifest、三个 PNG 图标、README.md 和本指南。
  3. 之后上传这些文件本身。不要上传 ZIP，也不要再包一层文件夹。

2．创建 GitHub 仓库

  1. 浏览器打开 github.com，注册或登录。
  2. 右上角 ＋ → New repository，或直接打开 github.com/new。
  3. Repository name 填 rouqian；如已占用，可填 rouqian-budget。
  4. 选择 Public。GitHub Free 支持公共仓库的 Pages；此仓库公开的是代码，不是你在网页里记的账。
  5. 勾选 Add a README file，其他先保持默认，再点 Create repository。

3．上传源码

  1. 进入仓库首页的 Code 页，点 Add file → Upload files。
  2. 在访达打开第 1 步的文件夹，选中里面所有文件，拖进网页上传区域。保留文件原名与大小写。
  3. 等待上传完成，在提交说明中填写 Upload Rouqian web app。
  4. 选择直接提交到 main，点 Commit changes。如果出现已有 README 的同名替换，使用本项目提供的 README 即可。
  5. 返回仓库首页，确认第一层就能看到 index.html。这是最容易选错的一步。

4．开启 GitHub Pages

  1. 点仓库上方 Settings，不是个人账号的 Settings。
  2. 左侧找到 Pages，通常位于 Code and automation 区域。
  3. 在 Build and deployment 中，Source → Deploy from a branch。
  4. Branch → main；旁边目录选 /(root)；点 Save。
  5. 等待自动构建。可在仓库 Actions 查看 pages build and deployment 是否完成。首次发布可能需要数分钟。
  6. 回到 Settings → Pages，以页面出现的 Visit site 为准。网址一般为 https://你的GitHub用户名.github.io/rouqian/。

打开的是 github.io 网站网址。github.com/用户名/rouqian 是源码仓库，不是运行中的 App。

5．Mac 上使用

  1. Safari 或 Chrome 打开 Pages 网址，即可操作。
  2. 在 macOS Sonoma 14 或更新系统中，可在 Safari 用 文件 → 添加到程序坞（Add to Dock），或分享菜单中的相同选项。
  3. 名称填「揉钱」，添加后从 Dock 打开。较旧系统直接用浏览器，并收藏网址即可。
  4. 如果浏览器里已有账单，先导出备份，打开 Dock App 后检查数据；如为空，再恢复备份。

6．iPhone 上使用

  1. 将 Pages 网址发到自己的手机，然后复制到 Safari 打开。
  2. 点 分享（方框向上箭头；部分布局在页面菜单内）。
  3. 选择 添加到主屏幕。若未看到，向下找「编辑操作」。
  4. 名称填「揉钱」。如出现 作为 Web App 打开 / Open as Web App 开关，打开它，再点「添加」。
  5. 回主屏幕点图标，首次联网打开，向下找到「离线缓存已准备」提示；之后可尝试飞行模式重新打开。初次加载未完成、缓存被回收或数据被清理时仍需联网。
  6. 请尽早选定主屏幕入口。Safari 和主屏幕 App 的数据不保证共享，已有数据先备份再恢复。

7．先用测试数据验收

  1. 新增「宠物」项目，额度设 0，确认出现在列表。
  2. 羽毛球 → 切一块 → 50 元，按住小块拖到买菜：买菜 250，羽毛球 50，总额 1,000。
  3. 记两笔相同备注、再记一笔不同备注，到「周期账单」查看合并是否符合预期。
  4. 预算设置将总额改为 500，重新填写分类额度并保存。
  5. 新周期开始后查看旧账单，累计三期可测试本期相对前两期均值。
  6. 关闭重开检查是否保留；导出一份备份确认能找到文件。正式记账前，测试账单可通过撤销最后操作处理；此版未提供整账本清空按钮。

8．Mac 与 iPhone 间转移账本

  1. 在数据完整的设备上，找到 数据与安装 → 导出备份。
  2. 确认得到 rouqian-backup-日期.json；Mac 通常在下载列表，iPhone 可保存到「文件」。同日多次下载可能自动加序号。
  3. 通过隔空投送或 iCloud Drive 把文件送到另一台设备。
  4. 在另一台设备打开揉钱，先备份当地账本，再在 从备份恢复 中选择 JSON，确认替换。
恢复会替换目标设备整个账本，不会合并两台设备各自新增的记录。当前建议用一台设备为主要记账设备，另一台按需导入最新备份。

9．常见问题

现象检查方式
404 页面确认 Actions 部署成功、来源为 main / root，仓库根目录有小写 index.html，以 Pages 的 Visit site 链接为准。
看到 README 或代码你可能打开的是 github.com 仓库。改用 github.io 网站网址，检查 index.html 是否上传到根目录。
页面无样式或按钮无反应确认 app.js、style.css 与 index.html 在同一级，文件名未被改成 app (1).js 等。
手机打不开网址先确认 Mac 能打开同一网址，再换手机的 Wi-Fi／蜂窝网络排查。GitHub Pages 在不同网络的可达性可能有差异。
没有主屏幕添加选项先用 Safari 打开完整网站链接；在分享列表向下滚动或编辑操作。
另一台设备没有账单这是本地账本，需手动导出／恢复。不是登录 GitHub 后自动同步。
显示保存失败立即导出备份；检查是否处于隐私浏览或存储空间不足。不要先清空数据。
更新后仍是旧版保持联网重新打开并刷新，确认 Pages 部署已完成。先导出备份；不要直接清除网站数据。

10．以后更新软件

先导出备份。在原仓库 Add file → Upload files，上传新版同名文件并提交。保持仓库名、Pages 设置、网址不变。我们每次发布源码更新都会更改离线缓存版本。更新代码不需要上传任何账本备份。

本版已完成逻辑验证；当前制作环境无法运行 Safari 或 iPhone 真机，需按第 7 步在你的设备确认。尚未登录你的 GitHub 创建仓库，也没有替你发布。
