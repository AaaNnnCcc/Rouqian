欢迎使用揉钱

感谢你选择揉钱，让我们一起为生活里的每一份需要，留出合适的预算。

这个月想吃好一点，下个月想多运动一些，偶尔也想为喜欢的东西留一点余地。生活在变化，预算也可以跟着调整。

揉钱的核心，是让你亲手调节额度，自由分配预算。 每个项目的预算都会显示为一条彩色额度。你可以像切面团一样，从一个项目中“切出”一部分，再拖到另一个项目中：一边变短，一边变长，总预算保持不变。

例如，从娱乐预算中切出 50 元，挪到买菜预算里，就能为这个月的餐桌多留一点空间。

点击项目下方的「切一块」，设置金额后，按住小块拖到目标项目即可；也可以直接选择转入的项目。已经花掉的金额不能再挪动，能自由调整的是剩余的额度。

你还可以按周或按月设置总预算，随时新增或删除项目，并在每笔支出发生后记录金额、分类和备注。在「周期账单」中，可以查看钱具体花在哪里，以及与以往周期相比的变化。

预算是帮助你安排生活的工具。希望揉钱能让每一次取舍，都更直观、更从容。

1．在 Mac 上使用

使用 Safari 或 Chrome 打开揉钱网址，即可开始使用。建议收藏网址，方便下次打开。

如果你的 Mac 使用 macOS Sonoma 14 或更新系统，还可以将揉钱添加到程序坞：

  1. 使用 Safari 打开揉钱。
  2. 在顶部菜单选择「文件 → 添加到程序坞」。
  3. 将名称设为「揉钱」，点击添加。
  4. 之后可以直接从程序坞打开。

较旧的 macOS 系统可以继续通过浏览器使用。

如果已经在浏览器中记过账，请先导出备份。 从程序坞打开后，如果没有显示原来的账本，再用备份恢复。

2．在 iPhone 上使用

将揉钱添加到主屏幕后，就能通过图标直接打开。

  1. 使用 Safari 打开揉钱网址。
  2. 点击「分享」按钮，通常是方框中带向上箭头的图标。
  3. 选择「添加到主屏幕」。如果没有看到，可向下滚动分享菜单，或查看「编辑操作」。
  4. 将名称设为「揉钱」。如果出现「作为 Web App 打开」开关，请开启，再点击「添加」。
  5. 返回主屏幕，点击揉钱图标。

首次从主屏幕打开时，请保持联网，等待页面下方出现「离线缓存已准备」提示。缓存准备好后，可以在离线时使用；如果缓存被系统清理，则需要重新联网加载。

建议选定一个固定入口记账。如果已经在 Safari 中记过账，请先导出备份；从主屏幕打开后，如未显示原账本，再恢复备份。

3．在 Mac 与 iPhone 之间转移账本

目前，揉钱的账本保存在各自设备中，Mac 与 iPhone 不会自动同步。 你可以通过备份文件转移账本。

  1. 在保存着最新账本的设备上，找到「数据与安装」，点击「导出备份」。
  2. 保存生成的文件，文件名类似 rouqian-backup-2026-10-02.json。Mac 上通常可以在下载列表中找到；iPhone 上可保存到「文件」。
  3. 通过隔空投送或 iCloud 云盘，将备份文件传到另一台设备。
  4. 在另一台设备打开揉钱。如果这台设备已有需要保留的记录，请先导出一份备份。
  5. 在「从备份恢复」中选择收到的文件，确认替换。

恢复备份会替换目标设备的整个账本，不会合并两台设备各自新增的记录。

建议以一台设备为主要记账设备，另一台按需导入最新备份，避免两边分别记账后遗漏记录。备份文件包含个人账目，请妥善保存，不要上传到公开的 GitHub 仓库。

4．常见问题

为什么打开后只有“Rouqian”标题，或者显示代码？

请确认打开的是揉钱的完整使用网址。GitHub 仓库页面用于存放代码；如果网址遗漏了软件所在的文件夹，也可能只显示项目名称。请使用发布者提供的完整链接。

网址打不开，或者出现 404，怎么办？

先检查网址是否完整。可以切换 Wi-Fi 或蜂窝网络重试；如果仍无法打开，请联系发布者确认网站是否正常。

页面没有样式，或者按钮没有反应，怎么办？

保持联网，刷新页面后重试。如果仍然异常，请将页面截图、设备型号及浏览器名称提供给发布者，方便排查。

为什么 iPhone 上找不到「添加到主屏幕」？

请先在 Safari 中打开网址，再查看分享菜单。该选项可能位于菜单下方，也可以查看「编辑操作」。

为什么另一台设备上没有我的账单？

账本保存在你记账时使用的设备和浏览器中，目前不会自动同步。请在原设备导出备份，再到另一台设备恢复。

为什么有些额度不能挪动？

已经发生的支出会保留在原项目中，只有尚未花掉的额度可以挪动。项目剩余额度为零时，就不能继续切出金额。

为什么总预算不能降到我想设置的金额？

当前周期的总预算不能低于已经发生的支出。如果是在规划下一个周期，请在「预算设置」中选择应用到「新周期」，再设置新的总额并分配项目额度。

页面显示保存失败，怎么办？

请立即导出备份，保留当前账本，再检查设备存储空间或浏览器是否限制了本地保存。不要先清除网站数据，以免丢失记录。

更新后仍然显示旧版，怎么办？

保持联网，关闭后重新打开并刷新。Mac 上可以尝试按「⌘ Command + Shift + R」强制刷新。如果仍未更新，请联系发布者确认更新是否完成。不要为了刷新版本直接清除网站数据。
